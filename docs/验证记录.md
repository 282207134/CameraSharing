## 业务断言

连续集成测试实际执行并断言：

1. 登录后进入首页，访问规格、相册和路线，手动输入四位相机编号。
2. 解锁相机后首页出现归还按钮，归还后产生一条新记录。
3. 初始余额 $72.01，归还后余额为 $67.91。
4. 历史搜索 `Nikon` 后不再显示 `Sony HX6`。
5. 添加测试卡 `4242 4242 4242 4242` 后，只保存末四位 `4242`。
6. 选择 $28 充值后余额为 $95.91。
7. 使用 `CAMSHARE1578` 后余额为 $105.91。
8. 修改姓名为 `Camshare Explorer` 后，重新加载独立的本地存储，姓名、余额、卡片、5 条租借记录与优惠码状态均正确恢复。
9. 集成测试结束清理独立测试存储键，不修改常规 App 的 `camshare.v1` 数据。

单元测试另外覆盖无效优惠码、重复优惠码、余额不足、未满四位编号、重复解锁、重复归还、卡号 Luhn 与过期日期。

## 布局与人工检查

375×812、402×874、320×568 三种逻辑尺寸逐页构建，包含进行中租借的首页状态，未检测到布局异常。键盘出现时隐藏底部导航，表单可滚动。

逐张查看运行截图后，修正了页标题与返回按钮重叠、银行卡号重复展示、资料页底部空白，以及小屏按钮、充值卡片和数字键盘的溢出问题。19 张界面截图在修正后重新采集；文档中的图片使用同一轮最终运行截图。

## 复现

```sh
./scripts/verify.sh
./scripts/verify.sh <模拟器设备ID>
```

第一条执行静态分析和单元 / 布局测试，第二条额外运行集成流程并生成截图。重新生成主要界面总览需 Python 与 Pillow：

```sh
python3 -m pip install Pillow
python3 scripts/create_overview.py
```

测试中的支付、扫码、定位与账号均为本地演示，不代表真实服务对接验证。当前验证确认了 Flutter UI、操作状态和本地数据行为。
